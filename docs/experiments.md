# Эксперименты этапа 0

20.11.2026, ПК `user-pc` (Ryzen 7 5700X, 16 потоков, 31 ГБ), OSS CAD Suite 20261118, Yosys 0.71+50.
Файлы – `experiments/`, запуск – `experiments/run_pc.sh <каталог> <файл.sby>`, результаты SBY – `experiments/build/` (в git не входят).

Общий пример (`experiments/common/dut_gray.sv`): насыщающийся счётчик Грея в домене A, синхронизатор 2FF шины в домене B. Параметр `BAD=1` – на шину идёт двоичный код.
